# Zomato Replica 🍕

A modern, responsive, and pixel-perfect front-end clone of the Zomato landing page built using clean HTML5, custom CSS3, and Tailwind CSS.

## 🚀 Features
- **Hero Banner:** Full-screen header with custom overlay and app download buttons.
- **Stats Section:** Key metrics highlighting scale, partner restaurants, and cities.
- **Zomato Gold Section:** Custom styled curved layout showcasing membership benefits.
- **Business Ecosystem Cards:** Clean grid layout displaying Eternal brands (*Zomato, Blinkit, District, Hyperpure*).
- **Fully Responsive:** Fluid typography and flexible flex/grid layouts optimized for mobile, tablet, and desktop views.

## 🛠️ Tech Stack
- **Structure:** HTML5
- **Styling:** CSS3 (Variables, Flexbox, CSS Grid)
- **Utility Framework:** Tailwind CSS (via CDN)
- **Icons:** Font Awesome 6.4.0

## 📂 How to Run
1. Download or clone the files to your computer.
2. Open `zomato.html` in any web browser.
